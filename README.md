# FastPack

A web app for organizing packing lists, items, and shared spaces.

## Getting Started

Install [Node.js](https://nodejs.org/) and npm, then run:

```sh
npm install
npm start
```

Open the URL printed by Vite (by default, http://localhost:3000/).

## Commands

- `npm start` or `npm run web`: start the development server.
- `npm run web:build`: build the production site in `dist/`.
- `npm run web:preview`: preview the production build.
- `npm run prebuild`: run typecheck, lint, unused-code checks, and unit tests.

## Project Structure

- `index.html` and `index.web.tsx`: browser entry points.
- `src/`: application components, navigation, services, and translations.
- `vite.config.ts`: development server and production build configuration.

Built with React, TypeScript, Vite, Firebase, and i18next.
